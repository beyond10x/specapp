## Commands

### RetireHarvest

**Retire a harvest.**

| field | type |
|---|---|
| `harvest_id` | `HarvestId` |
| `at` | `timestamp` |

| outcome | when | result |
|---|---|---|
| `no-such-harvest` (refused) | no such Harvest | `HarvestNotFound`: No harvest of this identity exists. |
| `retired` | otherwise | moves the **Harvest** `Active` → `Retired`; emits `HarvestRetired` |
| `wrong-state` (refused) | the Harvest is in a state that does not allow it | `HarvestStateConflict`: The harvest is not in a state this command acts from. |
