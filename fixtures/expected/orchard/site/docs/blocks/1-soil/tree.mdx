## Commands

### RetireTree

**Retire a tree.**

| field | type |
|---|---|
| `tree_id` | `TreeId` |
| `at` | `timestamp` |

| outcome | when | result |
|---|---|---|
| `no-such-tree` (refused) | no such Tree | `TreeNotFound`: No tree of this identity exists. |
| `retired` | otherwise | moves the **Tree** `Active` → `Retired`; emits `TreeRetired` |
